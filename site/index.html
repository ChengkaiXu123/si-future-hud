在 HUD 上直接审批Approve right there

「是否允许执行」带着完整命令弹到 HUD 上：批准一次、拒绝或始终允许。放着不管 10 分钟后交还给助手，从不替你决定。Requests arrive with the full command: Allow once, Deny or Always allow. Left alone, they go back to the agent after 10 minutes; it never decides for you.

首次安装First install

五分钟装好。Five minutes.

大部分时间在等 macOS 问你信不信任它。Most of it is macOS asking whether you trust it.

拖进「应用程序」Drag to Applications

打开 DMG，把 SI Future HUD 拖进「应用程序」。不要在 DMG 窗口里直接打开，否则自动配置不会生效。Open the DMG and drag SI Future HUD into Applications. Don't open it from the DMG window, or the automatic set‑up can't run.

放行一次Allow it once

临时签名的内部版本第一次会被拦下：「系统设置 → 隐私与安全性」点「仍要打开」。提示「已损坏」时运行：It's ad‑hoc signed, so the first launch is blocked: System Settings → Privacy & Security → Open Anyway. If it says "damaged", run:

xattr -dr com.apple.quarantine "/Applications/SI Future HUD.app"

每个助手的最后一步Finish each agent

终端里的 claude 登录一次；程小帮「插件」页启用一次 SI Future HUD；Cursor 在桌面版里登录。Sign in to the terminal claude once; enable SI Future HUD on Chengxiaobang's Plugins page; sign in to Cursor in its desktop app.

第一次打开时，它会自动：On first launch it sets itself up:

  • 给 Claude Code 装好插件，把「HUD 工具」加进 Claude Code 和 Codex；installs its Claude Code plugin and adds the HUD tools to Claude Code and Codex;
  • 打开「客户端回调」，让审批弹到 HUD 上；turns on client hooks so approvals reach the HUD;
  • 给程小帮放好插件。每一步只做一次，你删掉的不会再加回来。drops its plugin into Chengxiaobang. Each step runs once; nothing you remove is put back.

⚠️ 用之前请先看这几条⚠️ Read this before your first day with it

  • Claude Code 要装 claude 命令。HUD 通过它接入 Claude Code，只用桌面版也要装上，再重开 HUD；不然 Claude 收发不了传话。Claude Code needs the claude command. The HUD connects through it. Install it even if you only use the desktop app, then reopen the HUD; otherwise Claude can't send or receive messages.
  • Codex 不用另装。有 Codex 桌面版就行，HUD 直接用它自带的 codex 命令；只在终端里用 Codex 的，才要装 codex 命令行版。Codex needs nothing extra. With the Codex desktop app, the HUD uses the codex command built into it. Only terminal‑only Codex users need to install the codex CLI.
  • Claude 的额度要终端里的 claude 登录着。桌面 App 的登录和终端不共用；显示「已退出登录」时，在终端运行 claude 登录。Claude's quota needs the terminal claude signed in. The desktop app's sign‑in is separate; if it says signed out, run claude in a terminal and sign in.
  • Codex 只有桌面版的对话能收传话，对方正在干活时收不了。Codex receives only in desktop conversations, and not while a turn is running.
  • 程小帮每次重启后，要点开某个对话一次，那个对话才能收传话。After each Chengxiaobang restart, open a conversation once so it can receive.
  • 卸载要按顺序：先在设置里关掉「客户端回调」，再删 App。Uninstall in order: turn Client hooks off first, then remove the app.
